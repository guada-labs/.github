# Guada Labs — organization defaults

This repository holds organization-wide community health files:

- `CONTRIBUTING.md` — pointer to the shared Zuma contribution guide.
- `PULL_REQUEST_TEMPLATE.md` — default pull request description.
- `ISSUE_TEMPLATE/task.yml` — default issue form.

GitHub applies these defaults to every repository in the organization that does not define its own.

The canonical contribution guide lives at https://github.com/guada-labs/zuma/blob/main/CONTRIBUTING.md.
